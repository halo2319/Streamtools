# Repository Information

This repository contains two separate projects, each maintained on its own dedicated branch.

## Available Projects

### MOD-DECK
**Branch:** `mod-deck`

A moderator-focused tool designed to provide useful utilities and features for server staff. Mod Deck is intended to simplify moderation tasks and help streamline day-to-day server management.

### STREAM-CHAT
**Branch:** `stream-chat`

A streamer-focused tool designed to integrate multistream chat into OBS. The goal is to bring chat messages from multiple streaming platforms into one centralized interface, making it easier for streamers to manage their communities while live.

## Branch Directory

- `mod-deck` — Moderator utilities and tools.
- `stream-chat` — Multistream chat integration for OBS.

**Note:** Each project is maintained separately on its respective branch. Switch to the corresponding branch to access its files, updates, and documentation.
